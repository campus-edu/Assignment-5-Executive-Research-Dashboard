## Executive Overview

This dashboard delivers the standalone deliverable for **AI.135 Assignment 5: Executive Research Dashboard**. It synthesizes empirical research across Assignments 1 through 4 into an interactive strategic decision-making engine:

2. **Market Opportunity Meter (Assignment 3)**: Radial SVG opportunity gauges, audited SEC Form 10-K benchmarks (DoorDash CIK 0001792789; Uber CIK 0001543151), and a live Sensitivity Simulator.
3. **Expansion Readiness Gauge (Assignment 4)**: Statutory ranking of Texas (9.4/10), Florida (8.1/10), and California (4.2/10) with dynamic weight sliders and executive resolution of the Texas HB 2127 Contradiction Problem.
4. **Strategic Recommendations Hub (Assignments 1–4 Synthesis)**: Milestone-gated capital roadmap allocating the $2.0M Series A balance ($800K DFW beachhead, $1.2M Austin AI dispatch engine).
5. **1-Page Executive User Guide**: Embedded interactive document viewer and tutorial mode for executive onboarding.

## Deployment to GitHub Pages

1. Push this folder to a GitHub repository (e.g., `quickbite-assignment5-dashboard`).
2. Navigate to **Settings** > **Pages**.
3. Choose **Deploy from a branch** > branch `main`, folder `/ (root)`.
4. Click **Save**. The dashboard will be live in 60 seconds!
